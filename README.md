# Victorian Points Test Calculator 2026–27

A free single-page calculator for the Victorian Points Test (VPT), the ranking used for Victoria's subclass 190 and 491 skilled visa nomination. It scores applicants out of 950 using the 2026–27 tables, with age points for each year and salary in $5,000 bands.

Live: https://omkar-dev.github.io/victorian-points-calculator/

Static HTML with no build step. Not affiliated with the Victorian Government.
